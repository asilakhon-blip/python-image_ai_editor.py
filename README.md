# 🖼️ AI Image Editor (OpenCV + LM Studio)

Интерактивный консольный фоторедактор, сочетающий классические алгоритмы компьютерного зрения **OpenCV** и гибкость локальных языковых моделей через **LM Studio API**. Бот умеет парсить текстовые запросы пользователя, автоматически переводить их в параметры для матричных преобразований и выводить результат в графическом окне.

---

## 🌟 Ключевые особенности и возможности

* **Гибридное управление:** Переключение между детерминированными подменю (повороты, размытие, яркость) и интеллектуальными ИИ-командами.
* **ИИ-Парсинг (LLM в качестве Контроллера):** Модуль использует `system prompt` для жесткого форматирования ответов нейросети в валидный `JSON`. Никакой лишней болтовни от модели — только чистые параметры команд.
* **Автоматический трекинг версий:** Каждое успешное изменение шага автоматически сохраняет промежуточный файл (`*_step1.jpg`, `*_step2.jpg`), защищая от потери результатов.
* **Защита от русской раскладки:** Управляющие символы (`s`, `r`, `i`, `m`, `q`) продублированы для русской клавиатуры (`ы`, `к`, `ш`, `ь`, `й`), чтобы предотвратить случайные ошибки ввода.

## 🛠 Доступный инструментарий обработки

| Классические операции (Меню) | Интеллектуальные операции (ИИ) | Служебные команды |
| :--- | :--- | :--- |
| **[1] Поворот:** Афинные преобразования на произвольный угол. | **[4] Чёрно-белое:** Перевод в цветовое пространство `GRAY` через запрос к LLM. | **[s] Сохранить:** Принудительная фиксация текущего шага. |
| **[2] Разрешение:** Интерполяция `INTER_AREA` под HD, 800x600, 400x300. | **[8] Поиск краёв:** Детектор границ Кэнни (`Canny Edge Detection`) по ИИ-команде. | **[r] Сброс:** Возврат к исходной матрице изображения. |
| **[3] Red Channel:** Выделение красного канала (обнуление синего и зелёного). | | **[i] Инфо:** Просмотр текущего разрешения и веса картинки в ОЗУ. |
| **[5] Размытие:** Гауссово размытие с контролем нечётности ядра. | | **[m] Меню:** Повторный вывод графической таблицы. |
| **[6] Отражение:** Зеркальный разворот (X, Y, или обе оси). | | **[q] Выход:** Корректное закрытие окон `destroyAllWindows()`. |
| **[7] Яркость/Контраст:** Масштабирование через `convertScaleAbs`. | | |
