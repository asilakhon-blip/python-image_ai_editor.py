# 🖼️ AI Image Editor (OpenCV + LM Studio)

Интерактивный консольный фоторедактор, сочетающий классические алгоритмы компьютерного зрения **OpenCV** и гибкость локальных языковых моделей через **LM Studio API**. Бот умеет парсить текстовые запросы пользователя, автоматически переводить их в параметры для матричных преобразований и выводить результат в графическом окне.

---

## 🌟 Ключевые особенности и возможности

* **Гибридное управление:** Переключение между детерминированными подменю (повороты, размытие, яркость) и интеллектуальными ИИ-командами.
* **ИИ-Парсинг (LLM в качестве Контроллера):** Модуль использует `system prompt` для жесткого форматирования ответов нейросети в валидный `JSON`. Никакой лишней болтовни от модели — только чистые параметры команд.
* **Автоматический трекинг версий:** Каждое успешное изменение шага автоматически сохраняет промежуточный файл (`*_step1.jpg`, `*_step2.jpg`), защищая от потери результатов.
* **Защита от русской раскладки:** Управляющие символы (`s`, `r`, `i`, `m`, `q`) продублированы для русской клавиатуры (`ы`, `к`, `ш`, `ь`, `й`), чтобы предотвратить случайные ошибки ввода.

## 🚀 Настройка и запуск

### 1. Требования к окружению
Для корректной работы скрипта необходим Python версии 3.10+ и следующие библиотеки:
```bash
pip install opencv-python requests numpy

```

### 2. Подготовка локального ИИ-сервера (LM Studio)

1. Откройте **LM Studio**.
2. Загрузите любую компактную иструктированную модель (например, `Qwen-1.7B-Instruct` или `Llama-3-8B-Instruct`).
3. Перейдите во вкладку **Local Server** (значок сетевых стрелок слева).
4. Убедитесь, что порт выставлен на `1234`, и нажмите **Start Server**.

### 3. Запуск редактора

Положите любое изображение в папку с проектом или используйте встроенный пресет, после чего выполните команду:

```bash
python main_editor.py

```

*(Замените `main_editor.py` на реальное имя вашего файла, если оно отличается)*

## 👨‍нити Архитектурные фишки для защиты проекта

1. **Robust JSON Parsing:** В функции `ask_ai` реализована очистка ответа от Markdown-тегов (удаление префиксов `json и `), что предотвращает падение парсера `json.loads()`, если модель решила обернуть код в блоки.
2. **Афинная тригонометрия:** При поворотах изображения (функция `apply_command -> rotate`) автоматически пересчитываются новые границы матрицы (косинусы и синусы угла), благодаря чему края картинки **не срезаются** при повороте на 30, 45 или 60 градусов.
3. **Безопасность памяти:** Для сброса изменений не происходит повторного чтения с диска (медленный I/O) — вместо этого используется метод `.copy()` исходного объекта `numpy.ndarray`, хранящегося в оперативной памяти.
